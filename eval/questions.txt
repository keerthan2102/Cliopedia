# Cliopedia's retrieval question set.
#
# Each entry is a question plus the page numbers KNOWN to answer it. Running
# `python -m cliopedia.evaluate` asks each question and checks whether one of
# those pages came back in the top k. That is the retrieval hit rate — the one
# number that says whether the search half of this system actually works.
#
#
# ── The format ─────────────────────────────────────────────────────────────
#
#   ask:    the question, phrased as a student would ask it
#   pages:  printed page numbers, comma separated
#   why:    how you verified it — free text, any characters, any length
#
# A blank line ends an entry. Lines starting with # are ignored.
#
# There are NO quoting rules. Paste anything into `why`: quotation marks,
# apostrophes, dashes, text that wraps across five lines. A continuation line
# is simply any line that does not begin with `ask:`, `pages:` or `why:`.
# This file is written by hand, so it is designed not to break when you type
# in it.
#
#
# ── The trap to avoid ──────────────────────────────────────────────────────
#
# Do NOT write questions by running retrieval and recording what comes back.
# That measures whether retrieval agrees with itself, which it always will, and
# the score would be meaningless.
#
# Write them the other way round: open the PDF at a page, READ it, and write a
# question that page answers. The gold page is then the page you read, chosen
# independently of anything the system does.
#
# `pages` are PRINTED page numbers — the folio typeset on the page, not the
# PDF page. For this corpus the offset is 16, so PDF page 226 is printed page
# 210. The app reports printed pages, so the two compare directly.
#
# Spread the pages across the whole book. Twenty questions clustered in one
# chapter measure one chapter.
#
# Worth including on purpose: a few questions whose answer spans two pages
# (list both, either counts), and a few asked in a student's words rather than
# the textbook's — matching paraphrase is the whole reason for using embeddings
# instead of keyword search.
